The Trading Agent Bot runs four specialised sub-agents in parallel, each with its own capital pool, trading pairs, and EMA strategy. Every agent can be monitored and controlled independently from Telegram without touching the others. Status panels are interactive — buttons let you drill from the global overview directly into a single agent's detail view, then back again, entirely within one Telegram message thread. This page documents every per-agent command, what the detail message shows, and how capital rebalancing works when you activate or suspend the SpeculativeAgent (Tier 3).

---

## Status Commands

### Global Status

`/status` opens the main panel. It shows the bot state, total equity, open positions count, and a compact summary row per agent. At the bottom of that message, four inline buttons let you jump directly to any agent's detail screen:

```
⚡ Scalper T1        🚀 Momentum T2
🐋 Macro BTC/ETH    ⚠️ Especulativo T3
```

## Pause and Resume Individual Agents

Every sub-agent can be paused and resumed independently. Pausing an agent sets its internal `paused` flag; the agent's background thread keeps running (the scheduler stays alive) but trading evaluations are skipped on every cycle.

### Command syntax

```
# Full IDs
/pause_scalper_t1
/pause_momentum_t2
/pause_macro_btceth
/pause_speculative_t3

/resume_scalper_t1
/resume_momentum_t2
/resume_macro_btceth
/resume_speculative_t3
```

Short aliases also work via `/pause <alias>` and `/resume <alias>`:

```
/pause scalper
/pause momentum
/pause macro
/pause speculative

/resume scalper
/resume momentum
/resume macro
/resume speculative
```

### Pause reply example

```
⏸️ Agente ScalperAgent T1 (scalper_t1) pausado con éxito.

• Modo en que quedó: PASSIVE (⏸️ PASSIVE)
• Estrategia: TREND (5m)

Las operaciones de este sub-agente quedan suspendidas.
Para reactivar: /resume_scalper_t1
```

### Resume reply example

```
▶️ Agente MomentumAgent T2 (momentum_t2) reanudado con éxito.

• Modo en que quedó: ACTIVE (🟢 ACTIVO)
• Estrategia: TREND (15m)
• Capital Asignado: $20.00 USDT (40% del total)

El ciclo de trading evaluará oportunidades en el
siguiente cierre de vela (15m).
```

## Capital Rebalancing: Scenario A vs Scenario B

The orchestrator uses two capital distribution scenarios. Which scenario is active depends solely on whether `speculative_t3` is running in ACTIVE mode.

<CardGroup cols={2}>
  <Card title="Scenario B — Default" icon="pause">
    SpeculativeAgent is PASSIVE (0% capital). The three active agents split the entire pool:

    - ScalperAgent T1 → **50%**
    - MomentumAgent T2 → **40%**
    - MacroTraderAgent → **10%**
    - SpeculativeAgent → **$0.00**
  </Card>
  <Card title="Scenario A — T3 Active" icon="play">
    SpeculativeAgent is ACTIVE. Capital is redistributed across all four agents:

    - ScalperAgent T1 → **45%**
    - MomentumAgent T2 → **35%**
    - MacroTraderAgent → **10%**
    - SpeculativeAgent T3 → **10%**
  </Card>
</CardGroup>

Rebalancing is triggered automatically inside `resume_agent()` and `pause_agent()` in the orchestrator whenever the target is `speculative_t3`:

```python
# From tradingbot/core/orchestrator.py
async def resume_agent(self, agent_id: str) -> dict:
    self.agents[agent_id].resume()
    if agent_id == "speculative_t3":
        total = await self._fetch_total_capital()
        self._assign_capital(total, scenario_a=True)   # → Scenario A
    return self.agents[agent_id].get_status()

async def pause_agent(self, agent_id: str) -> dict:
    self.agents[agent_id].pause()
    if agent_id == "speculative_t3":
        total = await self._fetch_total_capital()
        self._assign_capital(total, scenario_a=False)  # → Scenario B
    return self.agents[agent_id].get_status()
```

## Activating the SpeculativeAgent (T3) from Passive Mode

The SpeculativeAgent starts in PASSIVE mode with zero capital assigned. The following steps show how to bring it online from your Telegram chat.

<Steps>
  <Step title="Check current state">
    Send `/status_speculative` or tap **⚠️ Especulativo T3** in the `/status` panel. Confirm the status shows `⏸️ PASSIVE` and `Capital Asignado: $0.00 USDT`.
  </Step>
  <Step title="Resume the agent">
    Send `/resume_speculative` (or `/resume_speculative_t3`). The orchestrator calls `resume_agent("speculative_t3")`, sets the agent to ACTIVE, fetches the current total equity, and redistributes capital using **Scenario A** (45/35/10/10%).
  </Step>
  <Step title="Verify capital rebalancing">
    The reply message confirms the new capital allocation:
    ```
    ▶️ Agente SpeculativeAgent T3 (speculative_t3) reanudado con éxito.
    • Capital Asignado: $5.00 USDT (10% del total)
    ```
    Check `/status` to confirm all four agents now show their new Scenario A allocations.
  </Step>
  <Step title="Confirm trading evaluations begin">
    Send `/status_speculative` again after one candle close (15 m timeframe). Total evaluations should increment from 0 and open positions may appear once a BUY signal fires.
  </Step>
  <Step title="Return to passive mode if needed">
    Send `/pause_speculative` at any time. Capital is redistributed back to **Scenario B** immediately, and the T3 agent stops evaluating opportunities without losing any historical data.
  </Step>
</Steps>

## Inline Keyboard Navigation Flow

The inline keyboards form a connected navigation graph. You never need to type a command after the initial `/status` — all transitions are button-driven:

```
/status  ──► agent_view:scalper_t1  ──► ⏸️ Pausar Agente
                                    ──► 🔄 Actualizar
                                    ──► ⬅️ Volver a Estado Global
         ──► nav:cashflow
         ──► nav:wallet
         ──► nav:matrix
         ──► stats_h:0 / stats_h:6 / stats_h:24
         ──► nav:why_block
         ──► nav:modes  ──► set_mode:trend / target / scalper
         ──► cmd:pause / cmd:resume
```

<Tip>
Tap **🔄 Actualizar** on any panel to refresh the data in-place without sending a new message. This keeps your chat history clean and avoids message spam during busy trading periods.
</Tip>
