Trading Agent Bot is a Python-based autonomous cryptocurrency trading system built around four specialized sub-agents that run in parallel, each managing its own capital pool, strategy, and trading pairs. The entire system is controlled in real-time through a Telegram chat interface — no web dashboard required.

## What Trading Agent Bot Does

The bot wakes up every minute, evaluates open positions and market signals across up to 16 trading pairs simultaneously, and executes buy/sell orders when strategy conditions are met — all without human intervention. It uses a **dynamic timeframe** system that switches between 1-minute candles during active market hours (13:00–17:00 UTC) and 5-minute candles during off-peak hours to reduce false signals.

## Get Started in 3 Steps

<Steps>
  <Step title="Install dependencies">
    Clone the repository, create a Python virtual environment, and install requirements.
    ```bash
    python -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Configure credentials">
    Copy `.env.example` to `.env` and set your Binance Testnet API keys plus your Telegram bot token. Set `PAPER_TRADING=true` to start safely.
  </Step>
  <Step title="Launch the bot">
    Run the entry point — the OrchestratorBot initializes all four sub-agents and connects to Telegram automatically.
    ```bash
    python main.py
    ```
  </Step>
</Steps>

<Note>
  Trading Agent Bot defaults to **paper trading** mode — real money is never spent until you explicitly set `PAPER_TRADING=false` and `EXCHANGE_TESTNET=false` in your `.env` file.
</Note>
